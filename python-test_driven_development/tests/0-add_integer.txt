===========================
How to Use 0-add_integer.py
===========================

Import the function:

>>> add_integer = __import__('0-add_integer').add_integer

Add two positive integers:

>>> add_integer(1, 2)
3

Add a positive and a negative integer:

>>> add_integer(100, -2)
98

Use the default value for b:

>>> add_integer(2)
100

Floats are cast to integers before adding:

>>> add_integer(100.3, -2)
98

Add two floats:

>>> add_integer(2.9, 0.2)
2

A non-numeric second argument raises TypeError:

>>> add_integer(4, "School")
Traceback (most recent call last):
TypeError: b must be an integer

A non-numeric first argument raises TypeError:

>>> add_integer(None)
Traceback (most recent call last):
TypeError: a must be an integer

A string first argument raises TypeError:

>>> add_integer("hello")
Traceback (most recent call last):
TypeError: a must be an integer

A None second argument raises TypeError:

>>> add_integer(4, None)
Traceback (most recent call last):
TypeError: b must be an integer
