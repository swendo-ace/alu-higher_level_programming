============================
How to Use 4-print_square.py
============================

Import the function:

>>> print_square = __import__('4-print_square').print_square

Print a square of size 3:

>>> print_square(3)
###
###
###

Print a square of size 1:

>>> print_square(1)
#

Print a square of size 0 (prints nothing):

>>> print_square(0)

Print a square of size 2:

>>> print_square(2)
##
##

A non-integer size raises TypeError:

>>> print_square("4")
Traceback (most recent call last):
TypeError: size must be an integer

A float size raises TypeError:

>>> print_square(4.5)
Traceback (most recent call last):
TypeError: size must be an integer

A negative size raises ValueError:

>>> print_square(-1)
Traceback (most recent call last):
ValueError: size must be >= 0

Calling with no argument raises TypeError:

>>> print_square()
Traceback (most recent call last):
TypeError: print_square() missing 1 required positional argument: 'size'
