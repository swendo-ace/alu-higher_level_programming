=========================
How to Use 1-my_list.py
=========================

Import the class:

>>> MyList = __import__('1-my_list').MyList

Check instantiation of an empty MyList:

>>> my_list = MyList()
>>> print(my_list)
[]

Check that MyList inherits from list:

>>> issubclass(MyList, list)
True

Check append() works (inherited from list):

>>> my_list = MyList()
>>> my_list.append(1)
>>> my_list.append(4)
>>> my_list.append(2)
>>> my_list.append(3)
>>> my_list.append(5)
>>> print(my_list)
[1, 4, 2, 3, 5]

Check __str__ (regular print):

>>> print(my_list)
[1, 4, 2, 3, 5]

Check print_sorted() with a not-sorted append, original stays unchanged:

>>> my_list.print_sorted()
[1, 2, 3, 4, 5]
>>> print(my_list)
[1, 4, 2, 3, 5]

Check print_sorted() with an already-sorted append:

>>> sorted_list = MyList()
>>> sorted_list.append(1)
>>> sorted_list.append(2)
>>> sorted_list.append(3)
>>> sorted_list.print_sorted()
[1, 2, 3]

Check print_sorted() with a negative number:

>>> neg_list = MyList()
>>> neg_list.append(5)
>>> neg_list.append(-3)
>>> neg_list.append(0)
>>> neg_list.print_sorted()
[-3, 0, 5]

Check print_sorted() with an empty list:

>>> empty = MyList()
>>> empty.print_sorted()
[]
